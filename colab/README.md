# Chạy code mới nhất trên Google Colab

Mở [notebook](./shared.ipynb) trên GitHub, rồi chọn **Open in Colab**. Chia sẻ notebook với các thành viên theo cách thông thường của Google Colab.

Chạy ô đầu tiên mỗi khi bắt đầu hoặc muốn cập nhật code. Ô này tải lại nhánh `main` từ GitHub vào một thư mục mới và đặt thư mục đó làm thư mục làm việc. Sau đó chạy các ô sử dụng code của dự án. Thay đổi phải được push và merge vào `main` trước khi Colab có thể tải được.

Notebook này tải code khi chạy; nội dung các ô notebook dùng chung không tự thay đổi theo code. Nếu repo là riêng tư, hãy cấu hình quyền truy cập Git trong Colab trước khi chạy ô đầu tiên; không ghi token vào notebook chia sẻ.
